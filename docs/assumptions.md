# 가정·미확인 항목·위험

확인됨은 자료/직접 관찰의 범위만, 제안은 신규 설계, 미확인은 증거 부족을 뜻한다. 담당자는 확인 요청 대상 후보이며 실제 배정이 아니다.

## 미확인 목록

| ID | 미확인 내용 | 영향·임시 대응 | 확인 방법·요청 대상 / 필요 시점 |
|---|---|---|---|
| U01 | 레거시 코드/DBMS/DDL/API/외부 계약 | 호환성 불명, 신규 논리 모델만 작성 | 읽기 전용 코드·비식별 DDL/API, 개발 담당 / Phase 1 설계 전 |
| U02 | 한글 레거시 화면과 실제 동작 | PRD 기록을 동작 증거로 취급하지 않음 | 화면별 운영자 시연 / Phase 2 범위 확정 전 |
| U03 | 마트/상품/사용자/파일/발송량 | 용량·비용·SLO 미확정 | 집계와 부하 프로파일 / Phase 1 목표 합의 |
| U04 | 인증/SSO/역할/마트 소속 | 격리·개인정보 위험 | 권한표·시험 계정, 관리자 / Phase 1 인증 전 |

| U11 | 엑셀 규격·최대행·미등록 의미 | 선행0 손실·오갱신 | 비식별 정상/오류 파일 / Phase 5 |
| U12 | 주문/회원/결제/배송/이벤트/계좌 조회 | 기능 누락·외부 부수효과 | 메뉴별 조사·연계 계약 / 해당 구현 전 |

| K02/P0 | 마트 간 조회·수정·파일 접근 | scope+복합FK+ID 변조 테스트 | 인증·권한 합의 필요 |
