# ADR 009 — 외부 연동 없는 UI 프로토타입 실행 범위

- 날짜: 2026-11-05
- 상태: 제안. UI 계약 검토·메인 동결 대상이며 운영 아키텍처 승인이 아니다.
- 근거: 최신 사용자 Phase 1 UI 프로토타입 요청, AGENTS.md의 최신 지시 우선, 기존 architecture ADR 001~008 보존.

## 문제와 대안

기존 하네스 Phase 1은 Java/DB/인증을 포함한 Running Foundation이고 선행 Discovery/활성화 gate가 BLOCKED다. 사용자는 이번 요청에서 백엔드/DB/클라우드를 제외하고 실행 가능한 React 데모를 명시적으로 허용했다. 대안은 (1) 전체 Foundation까지 확대, (2) 기존 차단만 보고 구현 중지, (3) 별도 UI 전용 계약과 검증으로 합성자료 브라우저 데모 구현이다. (1)은 범위를 위반하고 (2)는 최신 허용 범위를 충족하지 못하므로 (3)을 선택한다.

## 결정

기존 전체 Phase 0/1 gate와 `.codex` 준비/활성 상태를 변경해 PASS로 꾸미지 않는다. `frontend/`와 `docs/contracts/ui-prototype.*`를 UI 전용 산출물로 분리한다. `.codex/agents`가 없으므로 준비본 TOML 역할 지침을 collaboration Agent에 적용한 실행을 기록하고 네이티브 Custom Agent 호출이라고 하지 않는다. 원본 gate 스크립트를 완화하지 않는다. 최종 전체 gate 검사 실패와 UI 자체 인수 판정을 별도로 보고한다.

서비스 인터페이스 뒤 local adapter가 모든 합성자료와 LocalStorage를 관리한다. TanStack Query는 UI 캐시, Table은 검색/정렬/페이지/열 상태에 사용한다. 실제 API가 없으므로 서버 페이징/인증/트랜잭션/Outbox/내구 큐를 구현했다고 하지 않는다. OpenAPI는 향후 adapter 교체를 위한 연결점이며 미래 서버 명세 승인과 다르다.

합성 이미지 데모는 제한된 로컬 data URL 저장을 허용한다. 이것은 실제 DB byte 저장/서버 프록시를 도입한 것이 아니다. 서버 구현 단계에는 기존 private 원본+CDN+불변키 구조를 적용하고 local adapter를 교체한다. 실제 SMS 번호 입력과 외부 발송 요청은 제공하지 않는다.

## 영향·가정

UI를 실제 브라우저에서 검증할 수 있지만 LocalStorage는 사용자 변조/용량/유실/탭 경쟁에 취약하며 인증·테넌트 경계가 아니다. 실제 권한·PII·레거시 호환성·운영 SMS/이미지·복구 목표는 기존 U01~U16 미확인 상태를 유지한다. 데모의 바코드 중복/가격/수량 검증은 UI 시험용 가정이며 운영 규칙 확정이 아니다.

## 복구와 후속 연결

기존 문서와 운영 자료를 수정·삭제하지 않는다. 데모 초기화는 앱 namespace의 출처가 명확한 합성자료만 확인 후 재생성하며 다른 키/파일은 건드리지 않는다. 저장소 손상은 자동 덮어쓰기하지 않고 복구 안내한다. 소스 복구는 메인이 보존한 snapshot/해시를 기준으로 대상 파일만 다룬다. Git이 없으면 Git rollback 실행이라고 주장하지 않는다.

실 API 연결 단계에서는 별도 architect 계약·서버 인가·충돌/멱등성/부분 실패·OpenAPI 독립 검토를 새로 수행한다. local adapter 교체와 서비스 계약 테스트를 통해 UI 재작성을 줄인다. 기존 Foundation 후속 Phase는 원래 선행 gate가 해결되고 사용자가 허용한 범위에서만 시작한다.
