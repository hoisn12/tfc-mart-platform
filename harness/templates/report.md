# 작업 결과 보고

- task ID / Phase / Agent / 시도 번호 / 날짜:
- 상태: PASS | FAIL | BLOCKED | NOT_RUN
- 검증 범위: 계획 검토 | local/fake | 비운영 클라우드 (운영 실행 금지)
- 입력 스냅샷·계약 파일별 SHA-256:
- 변경 파일·요구사항/인수 조건 대응:
- 실행 환경·버전·명령·종료 코드·로그 경로 및 SHA-256:
- 계약/정상/실패/격리/보안 테스트 결과:
- 장애 주입→탐지→복구→정합성 결과:
- 앱 롤백/DB 호환·백업 복원·실측/목표 구분:
- 운영 연결·실SMS·기존 데이터 삭제가 없다는 확인 근거:
- 미완료·미실행·가정·차단 사유·잔여 위험:
- 다음 담당자에게 인계 / 잠금 해제 요청:

독립 reviewer는 위 범위와 입력 해시를 확인하고 심각도·파일/행·재현·영향·필요 수정/테스트와 최종 판정을 응답한다. 메인이 원문을 수정 없이 저장한다. 상태만 PASS이고 실행 증거가 없는 보고서는 gate 근거가 아니다.
