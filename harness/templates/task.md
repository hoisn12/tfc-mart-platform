# 작업 인계 양식

- task ID / Phase / 소유 Agent / 실행 모드(읽기 검토 또는 수정):
- 사용자 허용 범위 / 이전 gate 경로·SHA-256:
- 입력 문서·파일별 SHA-256 / 관련 요구사항·U/L/K ID:
- 승인 계약 파일·SHA-256 / 계약 검토·메인 동결 근거:
- 정확한 쓰기 파일 목록 / 활성 잠금 / 금지 경로:
- 생성·rename·도구 출력 파일 포함 여부:
- 산출물 / 완료 기준 / 필수 검증 명령·환경:
- 장애 주입·복구·롤백·운영 안전성 검증:
- 본인 고유 보고서 경로:
- 중단·에스컬레이션 조건 / 미확인:
- reviewer 검증 시: 작성자 불참 확인, 모든 쓰기 정지, 스냅샷, 읽기만 허용.

상위 폴더 전체를 쓰기 목록으로 대체하지 않는다. 계약이 없으면 Backend/Frontend의 모드는 읽기 검토다.
